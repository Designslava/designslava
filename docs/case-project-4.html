B2E Паттерн интерфейса

Фильтры

Отдельная работа внутри рабочего места контролёра. При потоке более 2500 задач в день список бесполезен без отбора: у каждого контролёра свой срез, и навязать один набор фильтров всем не получится.

Бизнес-требования

  • Гибкая фильтрация задач под разные роли и привычки
  • Сортировка там, где она нужна
  • Отдельный быстрый доступ к просроченным задачам

Решения

  • Фильтрация по любому элементу интерфейса — закрывает потребности всех ролей
  • Персональная настройка: фильтры переставляются перетаскиванием, часто используемые остаются в строке, остальные сворачиваются
  • Чекбокс «только просроченные» оставляет в списке одни просрочки
  • Диапазоны сумм и дат договора, поиск по ИНН, отбор по исполнителю, статусу и виду задания
  • Показываем количество найденных совпадений — видно, сработал ли отбор
  • «Сбросить всё» возвращает список в исходное состояние одним действием
Детали

Что учли в интерфейсе

Фильтр — это инструмент, которым пользуются десятки раз за смену, поэтому важнее гибкости оказалась скорость возврата в исходное состояние.

Настройка перетаскиванием. Контролёр оставляет в видимой строке свои три-четыре фильтра, остальные сворачивает. У каждого получается свой набор.

Только просроченные. Один чекбокс вместо комбинации из трёх условий: главный ежедневный сценарий вынесен в одно нажатие.

Диапазоны сумм и дат. Отбор по вилке значений, а не по точному совпадению — так контролёры и формулируют запрос.

Счётчик и сброс. Показываем число совпадений сразу, а «Сбросить всё» убирает накопленный отбор — без него пользователи разбирали фильтры по одному.

3 из 4 прошли
usability-тест

Usability-тест прошли 3 пользователя из 4, после чего фильтры вывели в промышленную эксплуатацию. Это часть рабочего места валютного контролёра, но паттерн проектировался отдельно — его переиспользуют другие разделы.
